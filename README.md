# CoachIQ

CoachIQ is a web app that helps sports coaches manage their teams, track performance, and share live dashboards with players and staff, all in one place.

## The Problem
Amateur and youth sports coaches often juggle spreadsheets, paper notes, and group chats to track their players and teams. This makes it hard to see performance trends, keep data organized, and share information quickly. Most existing tools are built for professional teams, so they are expensive and complicated for everyday coaches.

## Our Solution
CoachIQ gives coaches a simple, affordable tool to organize their teams and data and turn it into useful insights. Coaches can manage multiple teams, record and review information, and share live dashboards, without needing technical skills.

## Key Features
- Manage multiple teams from one account
- Live dashboards that can be shared with others
- Saved sports data with validation to protect against bad or damaged data
- Browser storage status and warnings so coaches don't lose their work
- Coaching demo mode to try the app quickly

## Running Locally
1. Clone this repository
2. Install dependencies: `pnpm install`
3. Start the app: `pnpm run dev`
4. Never commit real API keys or passwords. Use environment variables or Replit Secrets.
